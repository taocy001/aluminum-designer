## 型号与安装方式

连接件按厂家图纸或 STEP 建模，属性面板提供型号、来源、紧固件及安装要求。配件的尺寸和来源见[配件规格与安装](../docs/CONNECTOR-ACCESSORIES.md)。系列选择对应实物型号；同一型号不按系列比例放大。

| 类型 | 安装规则 |
| --- | --- |
| L 型角码 | 两个垂直安装面分别贴合对应型材，安装孔须对准槽线，定位凸台不能穿入槽壁 |
| 内角码 | 两条实际插脚进入各自宿主槽腔，紧定螺钉锁紧；肩部、槽唇与槽底共同决定位置 |
| 加强角码 | 40 系列中空三角角码，两个垂直安装面、通孔和斜面工具孔；20/30 系列没有已核验变体 |
| T 型角码 | 外贴五孔板，横梁三个孔和支臂两个孔分别连接两根型材 |
| 三维角码 | 40 mm 三向端面角块，三根 4040 的直切端面接入，端部中心孔须攻 M8 牙 |
| 直连板、对接板 | 外贴连接板，安装孔分组跨接两根共线型材，不嵌入槽腔 |
| 端盖 | 按完整截面选方盖或矩形盖，压入自由直切端；3040 没有已核验端盖 |
| 调节脚 | D40 M8 调节脚，安装于 3030/4040 朝下端面的 M8 螺纹孔，模型旋入 10 mm |
| 十字连接板 | 外贴七孔板，横梁五孔连接贯通杆，两侧各连接一根杆；20 系列没有已核验型号 |
| 滑块螺母 | 匹配 B6、B8 或 I8 槽系，肩部置于槽唇后方；不附螺栓 |
| 合页 | 两扇独立叶片分别连接两个构件，每叶两个沉头孔，铰轴平行安装面 |
| 轴承座 | Ø10 轴孔平行底面，两安装孔沿一根型材的同一槽线布置 |
| 脚轮 | 原厂完整轮架、转盘及轮轴；官方页面与图纸的安装尺寸不同，当前只显示独立样品 |

## 选位与编辑

选择器用实际模型缩略图显示连接件；悬停或键盘聚焦时显示名称和安装说明。选中后，实体预览跟随鼠标，靠近有效安装位时自动吸附；在画布中点击放置后，继续移动鼠标可安装下一件。

安装面板可筛选连接构件、槽位和朝向；`Tab` / `Shift + Tab` 轮选。使用这些选位操作、面板内的放置按钮或「固定节点」后，当前节点保持固定，便于旋转视图检查和连续安装。点击「选择其他节点」恢复鼠标跟随。

预览高亮关联型材、安装面和槽线。被占用或发生干涉的候选位置仍可查看，并显示原因。实际孔位相同的对称姿态只算一个安装位。

选中已有连接件后，可修改位置和角度；角接件还可通过「重新安装」选择新安装位。重新安装排除自身占位；自由移动后的件仍参加安装审计。镜像三维角码时，按目标支承重新寻找可用位置；没有可用安装位则取消操作。

「连接所有接头」枚举当前类型的构件组合、槽线和方向，补齐可用位置，并保留已有连接件。手动安装、重新安装和自动补齐共用安装孔、占位、型材、板件、门抽屉及设备预留检查。贴面件由用户指定安装位置。

## 槽系与数量

2020 和 2040 对应 B 型槽 6，3030 对应 B 型槽 8，4040 对应 I 型槽 8。2040 的 40 mm 面有两条槽，槽距 20 mm；4040 的 40 mm 面只有一条中心槽。3040 没有已核验厂家截面，不能据其名义边长推定连接件适配。

两根 2040 的双槽面垂直相接时，两槽均可参与候选计算。三方向节点分别检查三组两两组合，但最终数量由对应实物的槽系、孔位、插脚和周围空间决定。B6 内角码不能直接连接 I8 型材；30 B8 和 40 I8 共用的内角码仍须按各自槽唇确定每条臂的埋深。两根 2040 加一根 4040 的节点不能仅凭轴线位置认定有五个可用内角码位置。

## 检查与清单

连接件按实际网格和各块实体选择；轮廓外保留 20 px 选取容差，重叠处可用 `Tab` / `Shift + Tab` 切换。

连接件与型材的碰撞使用真实截面，包括槽内扩腔和中心孔。连接件采用分开的翼板、肩部、插脚、轮架等实体，避免把开放区域填满。匹配端盖的塑料卡脚允许有限压入过盈；调节脚只有同轴 M8 螺杆允许进入需攻牙的中心孔。盖板、锁紧螺母、第三根型材、板件和设备仍参加干涉检查。

BOM 按具体型号统计紧固件：内角码列紧定螺钉，调节脚列随件锁紧螺母，外贴连接板列各孔螺钉和槽螺母，未核定安装的脚轮不推定紧固件。端盖按 2020、2040、3030、4040 分开统计。未指定长度的螺钉不会用系列默认值补齐。

抽屉两侧支撑梁和分仓型材属于框架，连接件计入工程和清单。「补齐滑轨支撑」只在支撑与连接位置均有效时提交；「加抽屉」不自动生成分仓结构。

模型与检查不包含连接强度验算、安装顺序及工具操作空间，具体加工和采购应依据所列产品资料。
