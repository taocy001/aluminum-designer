# 连接件模型与安装规则

![连接件展示](connector-demo.png)

在侧栏「打开」中载入 [connector-demo.json](connector-demo.json)，可查看 14 种连接件、15 个实例。
L 型角码分别用于 L 角接和 T 接示例。角接件有安装面及孔位回归检查；展示工程不参加家具装配检查，模型未对应具体厂商的产品尺寸。

## 目录

| 连接件 | 模型与用途 |
|---|---|
| L 型角码 | 两个垂直翼板，放在两根型材围成的内直角处 |
| 内角码 | 两条垂直插脚，沿相邻型材的槽布置 |
| 加强筋 | 三角平板，用于角部的外侧平面 |
| T 型角码 | T 形平板，用于端部与中段相接的接头 |
| 三维角码 | 沿三个轴伸出的角件，用于三根正交型材的角点 |
| 直连板 | 外侧连接板，用于共线型材接长 |
| 对接板 | 沿槽线放置的连接板，用于共线型材接长；模型中面贴型材表面 |
| 端盖 | 端面盖板和插入段 |
| 脚轮座 | 柱底安装座，带简化轮形显示 |
| 调节脚 | 底盘、支杆和顶板，没有可调行程参数 |
| 十字连接板 | 十字形平板，贴面放置 |
| 滑块螺母 | 槽内螺母示意件 |
| 合页 | 贴面安装的合页示意件 |
| 轴承座 | 底板和轴承示意件，贴面放置 |

连接件按 20、30、40 系列缩放，系列由安装位置附近的型材推断。
螺栓与螺母在 BOM 中按目录配方统计，需根据所选实物连接件确认孔距、螺纹、长度和数量。

## 放置方式

在侧栏选择角接件后，移动鼠标查看预览，点击放置并固定当前节点。
安装面板可筛选连接构件，点击编号选择槽位和方向，再点击「放置」；`Tab` / `Shift + Tab` 可轮选。
预览高亮关联型材、安装面和槽线。可先点击「固定当前节点」选择位置，固定后可旋转视图查看。点击「选择其他节点」解除固定。

占用或干涉的位置仍可预览，并显示不能安装的原因。按实际孔位识别重复件，交换对称安装臂不产生新安装位。
选中已有连接件后，可在侧栏修改位置和角度；角接件还可用「重新安装」切换构件组合、槽位和朝向。重新安装排除自身占位；自由修改允许暂时离开安装面，并显示安装检查结果。

三维角码的实体和孔面不对称。镜像时按目标位置的可用安装面重新定位，并提示结果；没有可用安装位时取消整次镜像。

| 落位类别 | 连接件 | 位置计算 |
|---|---|---|
| 内直角 | L 型角码、内角码、三维角码 | 根据相邻型材的朝向、截面和槽线计算角部位置 |
| 外侧平板 | 加强筋、T 型角码 | 查找两根型材的共面外侧面与槽线 |
| 端部 | 端盖 | 使用型材实际裁切或延伸后的端点，并跟随端面朝向和截面转角 |
| 柱底 | 调节脚、脚轮座 | 在附近查找立柱下端，按连接件的模型基准落位 |
| 对接 | 直连板、对接板 | 按指定位置放置，结合附近型材确定朝向 |
| 贴面 | 十字连接板、滑块螺母、合页、轴承座 | 按指定位置与命中面的法向放置 |

「连接所有接头」枚举当前类型的构件组合、槽线和两侧方向，并补齐可用位置。已有连接件全部保留；同槽不同侧在孔位有效、互不干涉时可同时安装。
角接件的手动安装、重新安装和自动补齐共用孔位、占位、型材、板件、门抽屉及设备预留检查。
端盖使用自由端的实际端面，调节脚和脚轮座只处理朝下的端部；贴面件需要手动指定位置。

抽屉分仓的中柱和两侧安装梁属于型材结构，其连接件与外框一样计入工程和清单。
「加抽屉」不自动生成这些型材或连接件。选中抽屉后可用「补齐滑轨支撑」添加缺少的侧梁及其连接件；每只抽屉只有在两侧支撑和连接位置都有效时才提交。中间分仓型材仍需单独设置。

仅凭预览出现、零件已加入模型或 BOM 数量满足，不能确认实际安装可行。

## 截面与槽线

自动角部落位首先检查两个截面是否有共同的名义边宽。例如 2020 与 2040 共享 20mm 边，
2040 与 4040 共享 40mm 边；2020 与 4040 在此规则下没有共同边，不生成这类角部座位。
这是本工具的简化角部匹配规则，不是实物连接件的完整兼容目录。

实际落位还取决于型材姿态和槽的位置：

- 模型中 20mm、30mm 宽的面各有一条中心槽，40mm 宽的面有两条槽，距面中心分别为 ±10mm。
- 两根 2040 在 40mm 安装面垂直对接且双槽对齐时，两个槽位都可手动安装或自动补齐；三方向接头检查全部三组两两配对。
- 角件的两条安装臂需分别对准宿主型材的槽线；平板枚举共面面的正反侧及槽线，T 板横梁的两个孔和支臂孔都需有支承。
- 截面转角及横向偏移会改变可用安装面，同一规格组合不能仅凭“居中”或“齐平”判断是否可装。
- 安装检查按实际裁切后的型材范围验证螺栓落面，三维角码还检查第三条安装臂。

书桌左后上角由两根水平 2040 和一根竖直 4040 构成，共有五个内角码位置：两个梁柱连接各两个，梁梁连接一个。其他连接件按各自孔距、安装面和外形判断，数量不一定相同。

## 检查范围

选择连接件时，各块实体的投影轮廓外有 20px 容差，真实网格遮挡优先；重叠处可用 `Tab` / `Shift + Tab` 轮选。

连接件按翼板、插脚等分块几何检查，圆弧部件使用各自的包围盒。普通 L 型角码的装饰加强筋不参与干涉检查。
型材包围盒不含槽形，内角码插脚不参与对型材的碰撞检查；滑块螺母仅在槽线、朝向和安装面匹配时豁免插入部分。与其他连接件、板件和设备仍检查完整几何。实际槽形、插入路径和紧固工具空间需另行核对。

调节脚的 20 系列显示模型总高为 31mm，顶板上表面与立柱底端接触；它没有行程调节。脚轮座也以安装顶面定位。
端盖、脚轮座、合页等显示模型没有具体厂商规格，不能直接用作加工图。

材料数量、外观和几何检查均不包含连接强度验算。承载、固定方式及采购规格需按实际零件确定。
