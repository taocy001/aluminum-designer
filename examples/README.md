# 示例工程

本目录包含六份独立家具工程、`flat/` 中的十二份柜体工程，以及连接件展示工程。
在侧栏「打开」中载入 JSON，可编辑零件并从「导出」生成物料清单、下料单、DXF、STEP 和带图装配说明 HTML。
PNG 用于预览，不能作为工程文件导入。含双开门的示例使用工程格式 v6，需使用支持 v6 的程序打开；其他示例的旧格式仍可导入。

尺寸单位为毫米。型材外包尺寸按修剪后的型材计算，不含门板、脚、拉手等外伸件。
表中的独立板件数量不含门和抽屉生成的板件；后者另计入物料清单。

### L 形橱柜

![L 形橱柜](kitchen-l-shaped.png)

工程文件：[kitchen-l-shaped.json](kitchen-l-shaped.json)。长边包括水槽柜门、双抽屉和转角区，
回转边包括转角区与一扇柜门。转角区未安装门或拉篮。两条边的门分别朝 +Z 和 −X。
工程含一块层板，不含台面、水槽和灶具。

### 四门衣柜

![四门衣柜](wardrobe-2-door.png)

工程文件：[wardrobe-2-door.json](wardrobe-2-door.json)。采用 4040 立柱、2040 横梁和 2020 挂杆，
含三块层板、四扇门和两只内嵌抽屉。两根挂杆的轴高分别为 1690mm、1090mm。
两个净宽 840mm 的开口各装一对双开门，每扇门板为 433.5×2130mm，中缝 3mm。
右侧为上下两只抽屉，每只安装开口净宽 840mm，面板宽 834mm，两侧均有滑轨安装梁。
使用抽屉前需同时打开右侧两扇外门；门抽五金仍需按实际尺寸和载荷选型。

### 书桌

![书桌](desk-with-pedestal.png)

工程文件：[desk-with-pedestal.json](desk-with-pedestal.json)。左侧为腿部空间，右侧为三只抽屉。
采用 4040 桌腿和 2040 横梁，腿部空间没有前底梁。型材顶面高度为 720mm。
工程没有桌面板，桌面尺寸、厚度和安装方式需另行设计；不包含桌面的材料或下料数量。

独立家具中，L 形橱柜最宽门板为 592×812mm，抽屉净宽 580mm；四门衣柜每扇门板为 433.5×2130mm，
抽屉净宽 840mm；书桌抽屉净宽 440mm。高书架、开放展示架和工具车没有门或抽屉。

双开门在每个开口中间留 3mm 缝，外侧按原盖合方式覆盖框架。厨房水槽、碗柜每扇门板宽分别为
394.5mm、344.5mm；吊柜三对门每扇分别为 394.5mm、309.5mm、344.5mm，窄档门板宽 292mm。
厨房地柜使用一列上下两抽，抽面半盖；电视柜使用两列抽屉，半盖抽面跨 20mm 中间型材，左右面板间距为 8mm。
上下相邻的抽面间距为 3mm。各列抽屉两侧均有贯穿深度的实物安装梁，进入型材下料清单。
flat 的电视柜与书桌抽屉统一朝 −Z；厨房地柜的门和抽屉统一朝 +Z。

部分相邻门的最大开启角为 90°，其余上述双开门为 110°：

| 工程 | 最大开启角为 90° 的门 |
|---|---|
| 01 厨房地柜 | 拉篮预留位窄门、碗柜左门 |
| 02 厨房吊柜 | 左柜右门、洗碗机上方柜左门、窄门、最右柜左门 |
| 06 主卧衣柜、独立四门衣柜 | 两个开口之间相邻的两扇门 |

上述角度按工程中的 `swing` 参数模拟。实物需要选择对应的限位铰链或限位件；
限位机构没有建模，也不会自动进入 BOM。更改开启角后应重新检查邻门的运动范围。

以下尺寸需要在五金选型时重点核对：

- 06 主卧衣柜单扇门板为 493.5×2350mm，独立四门衣柜为 433.5×2130mm；高度和实际板重仍需纳入铰链选型。
- 03 高柜门板为 610×2250mm；04、10、11 的门板分别为 592×1972mm、590×2150mm、592×1972mm，需核对所选铰链允许的门宽、门重及安装条件。
- 05 电视柜抽屉净宽 580mm、面板宽 592mm，01 灶下抽屉净宽 930mm、面板宽 942mm；滑轨载重、抽箱底板承托和灶具底部空间仍需按用途确认。
- 独立四门衣柜抽屉净宽 840mm，需同时打开右侧两扇外门；抽拉通道和实际铰链突出量需按实物五金复核。

BOM 中的铰链数量是按门尺寸计算的简化建议，不是承载验算。
[Blum 的铰链数量说明](https://ea.blum.com/en/number-of-hinges/)将重量、尺寸和材质列为选型因素，
其数量表以门宽不超过 600mm 为基础；该条件不能作为所有铰链的统一宽度上限。

## 几何检查与模型范围

示例回归检查包括：

- 型材、连接件、板件和门抽板件之间的包围盒干涉。
- 接头的截面及槽线匹配、已安装角码的螺栓落面，以及同位同姿态重复连接件。
- 水平层板四边的承托范围、承托宽度和顶面高度。
- 抽屉两侧安装面的方向、深度与开口位置。
- 构件关闭、单独完全打开和同步完全打开时的干涉；内嵌抽屉先打开遮挡它的外门。

门间运动检查另以不超过 1° 的角度间隔采样，涵盖邻门关闭、半开、全开和同步运动。
这些检查使用简化几何，不包含所有独立开合角度组合，也不计算结构承载、稳定性或工具可达性。
BOM 的对接端与角码总数用于材料估算，不能单凭总数确定每个接点的实际连接情况。

工程仅包含 JSON 中列出的部件。桌面、台面、侧封板、背板、电器和五金以各文件实际配置为准。
未建模的部件不会进入清单。拉手和连接件为简化模型，具体滑轨、铰链安装座、挂墙件、防倾倒件、
踢脚板及管线等需要另行设计或选型。

调节脚没有可调行程参数。20 系列显示模型总高为 31mm，其中一部分伸入立柱，其他系列按比例缩放；
模型总高不能直接当作柜体增高量。成品高度应结合脚的安装位置及台面等部件计算。
更多功能边界见[范围与限制](../docs/ROADMAP.md)。

## 生成预览和物料清单

在仓库根目录启动开发服务：

```bash
npx vite --port 5174 --strictPort
```

另开终端运行以下命令；需要可用的 Playwright Chromium：

```bash
node scripts/capture-examples.mjs
```

脚本生成六份独立家具的 PNG 与 BOM CSV，以及十二份 flat 工程的合照。
