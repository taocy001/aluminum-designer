# 示例工程

本目录包含六份独立家具工程、`flat/` 中的十二份柜体工程，以及连接件展示工程。
在侧栏「打开」中载入 JSON，可编辑零件并从「导出」生成物料清单、下料单、DXF、STEP 和带图装配说明 HTML。
PNG 用于预览，不能作为工程文件导入。请使用支持 4040 B6 型材及当前连接件型号的版本打开。

尺寸单位为毫米。型材外包尺寸按修剪后的型材计算，不含门板、脚、拉手等外伸件。
表中的独立板件数量不含门和抽屉生成的板件；后者另计入物料清单。

### L 形橱柜

![L 形橱柜](kitchen-l-shaped.png)

工程文件：[kitchen-l-shaped.json](kitchen-l-shaped.json)。长边包括水槽柜门、双抽屉和转角区，
回转边包括转角区与一扇柜门。转角区未安装门或拉篮。两条边的门分别朝 +Z 和 −X。
工程含一块层板，不含台面、水槽和灶具。

### 四门衣柜

![四门衣柜](wardrobe-2-door.png)

工程文件：[wardrobe-2-door.json](wardrobe-2-door.json)。采用 4040 B6 立柱、2040 B6 横梁和 2020 B6 挂杆，
含三块层板、四扇门和两只内嵌抽屉。两根挂杆的轴高分别为 1690mm、1090mm，两端各由同高的侧梁连接至立柱。
两个净宽 840mm 的开口各装一对双开门，每扇门板为 433.5×2130mm，中缝 3mm。
右侧为上下两只抽屉，每只安装开口净宽 840mm，面板宽 834mm，两侧均有滑轨安装梁。
使用抽屉前需同时打开右侧两扇外门；门抽五金仍需按实际尺寸和载荷选型。

### 书桌

![书桌](desk-with-pedestal.png)

工程文件：[desk-with-pedestal.json](desk-with-pedestal.json)。左侧为腿部空间，右侧为三只抽屉。
采用 4040 B6 桌腿和 2040 B6 横梁，腿部空间朝抽屉正面（+Z）开放，底横梁设在后侧。型材顶面高度为 720mm。
前上横梁左端位于 x=40mm，与左桌腿内侧齐平；左前上角可同时安装五只内角码：桌腿与两根横梁各两只，两根横梁之间一只。
工程没有桌面板，桌面尺寸、厚度和安装方式需另行设计；不包含桌面的材料或下料数量。

### 高书架

![高书架](bookcase-tall.png)

工程文件：[bookcase-tall.json](bookcase-tall.json)。型材外包为 900×2000×320mm，立柱及顶底框采用 2040。
五层侧梁采用 2020，前后 2040 横梁放平。五块内嵌密度板均为 860×240×18mm，中心高度为 355、700、1050、1400、1700mm。
每块板的四边各用两组两孔连接板固定；板上有 Ø5.5mm 通孔，第一层采用 6mm 垫套，其余四层采用 1mm 垫套。
板材固定件的槽螺母、穿板螺栓、垫圈、螺母及垫套均列入清单，安装方式见[板材固定](../docs/CONNECTOR-ACCESSORIES.md#板材固定)。
底框截面的竖向尺寸为 40mm，顶框竖向尺寸为 20mm。工程没有挂墙件或防倾倒件。

### 工具车

![工具车](rolling-cart.png)

| 工程 | 最大开启角为 90° 的门 |

限位机构没有建模，也不会自动进入 BOM。更改开启角后应重新检查邻门的运动范围。

以下尺寸需要在五金选型时重点核对：

- 06 主卧衣柜单扇门板为 493.5×2350mm，独立四门衣柜为 433.5×2130mm；高度和实际板重仍需纳入铰链选型。
- 03 高柜门板为 610×2250mm；04、10、11 的门板分别为 592×1972mm、590×2150mm、592×1972mm，需核对所选铰链允许的门宽、门重及安装条件。
- 05 电视柜抽屉净宽 580mm、面板宽 592mm，01 灶下抽屉净宽 930mm、面板宽 942mm；滑轨载重、抽箱底板承托和灶具底部空间仍需按用途确认。
- 独立四门衣柜抽屉净宽 840mm，需同时打开右侧两扇外门；抽拉通道和实际铰链突出量需按实物五金复核。

BOM 中的铰链数量是按门尺寸计算的简化建议，不是承载验算。
[Blum 的铰链数量说明](https://ea.blum.com/en/number-of-hinges/)将重量、尺寸和材质列为选型因素，
其数量表以门宽不超过 600mm 为基础；该条件不能作为所有铰链的统一宽度上限。

## 连接件安装范围

型材截面采用 2020/2040 B6、4040 B6 双槽型材，以及工具车的 3030 B8。独立书桌、独立四门衣柜和 flat 的 03、06、10 使用 4040 B6 立柱，与其 2040/2020 B6 横梁及挂杆匹配。4040 B6 每面两槽，不能用每面单槽的 4040 I8 替代。

十八份家具工程均已安装连接件，型材连接图为单一装配体；每个接头附近的构件通过实际安装孔相连。内嵌层板通过四边分布的连接板固定至主框，贴框背板通过穿板螺栓和槽螺母固定，衣柜挂杆两端有侧梁支撑。检查涵盖型号、孔位、局部连接关系和实体干涉，不代替承载或抗倾覆验算。
运行 `npx vite-node scripts/audit-example-hardware.ts` 检查各工程的连接件安装、零件干涉、板材固定及接头连通情况；结果输出到终端，检查失败时以非零状态退出。单元测试直接检查样例几何与连接关系。

## 几何检查与模型范围

示例回归检查包括：

- 型材、板件和门抽板件的包围盒干涉，以及连接件分块实体的干涉。
- 接头的截面及槽线匹配、已安装连接件的安装面，以及安装孔位相同的重复连接件（包括对称朝向）。
- 所有型材属于同一连接图，且各接头附近通过实际紧固孔连接，避免悬空挂杆或独立承托环。
- 水平层板四边的固定件有效性；每边至少两件且紧固孔跨度覆盖半条边长。背板四个外侧象限均有有效固定点。
- 抽屉两侧安装面的方向、深度与开口位置。
- 两份书桌按各自抽屉朝向检查腿部入口，从地面到上梁下方没有前横梁，并保留后底梁。
- 构件关闭、单独完全打开和同步完全打开时的干涉；内嵌抽屉先打开遮挡它的外门。

门间运动检查另以不超过 1° 的角度间隔采样，涵盖邻门关闭、半开、全开和同步运动。
这些检查使用简化几何，不包含所有独立开合角度组合，也不计算结构承载、稳定性或工具可达性。
BOM 的对接端与角码总数用于材料估算，不能单凭总数确定每个接点的实际连接情况。

工程仅包含 JSON 中列出的部件。桌面、台面、侧封板、背板、电器和五金以各文件实际配置为准。
未建模的部件不会进入清单。拉手和连接件为简化模型，具体滑轨、铰链安装座、挂墙件、防倾倒件、
踢脚板及管线等需要另行设计或选型。

03、06、10 的 D40 M8×50 调节脚使用 40×40×8mm 加工转接板：四颗 M6 沉头螺钉连接立柱四个攻牙芯孔，有效攻丝深度至少 13mm，板中心 M8 孔安装脚。转接板是工程设计件，需按图加工；4040 B6 的中央空腔不能直接安装 M8 脚。
这三例以型材柱底 y=0 为标高基准，脚底为 y=−76.24mm；含脚总高分别为 2376.24、2476.24、2276.24mm。模型没有可调行程参数，台面等外加部件需另计高度。
更多功能边界见[范围与限制](../docs/ROADMAP.md)。

## 生成预览和物料清单

在仓库根目录启动开发服务：

```bash
npx vite --port 5174 --strictPort
```

另开终端运行以下命令；需要可用的 Playwright Chromium：

```bash
node scripts/capture-examples.mjs
```

脚本生成六份独立家具的 PNG 与 BOM CSV、十四种连接件的近景图集，以及十二份 flat 工程的合照。
传入示例名称可只更新该示例，例如 `node scripts/capture-examples.mjs bookcase-tall`。
高书架的内嵌层板结构及固定件可运行 `npx vite-node scripts/generate-bookcase.ts` 重建；所有家具样例的层板与背板固定可运行 `npx vite-node scripts/generate-example-panels.ts` 生成；重复运行不会增加重复固定件。随后重算硬件检查并更新预览与清单。
