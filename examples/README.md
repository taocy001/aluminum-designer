### L 形橱柜

![L 形橱柜](kitchen-l-shaped.png)

长边 2400 靠墙（z=0），回转边 1850 沿另一面墙，内转角在 (1750, 650)。
长边三档：水槽柜门 / 灶下双抽 / **转角位**；回转边两档：转角位延伸 / 一扇门。

转角区未安装柜门。普通门板延伸至内转角柱时会与相邻横梁相交；转角取物机构未建模。

### 双开门衣柜

![双开门衣柜](wardrobe-2-door.png)

**4040 立柱 + 2040 横梁**，横梁往外推 10mm 与立柱外表面齐平——这是角码能同时贴住两根的前提。
左档长衣区（挂杆 1690）、右档短衣区（挂杆 1090 + 隔板 1150）+ 两只抽屉，顶部通长被褥格。
挂衣杆采用横跨开口的 2020 型材。

### 书桌

![书桌](desk-with-pedestal.png)

**一半是腿部空间，一半是抽屉柜**，桌面横跨两者。
腿部那一档**没有前底梁**，脚才伸得进去；只在抽屉柜那档做完整底框，
后侧补一根横撑抗扭。4040 桌腿，框架中心线 720，加 18mm 桌面后完成面 748。

### 高书架

![高书架](bookcase-tall.png)

900 宽、2000 高、320 深——又高又浅，五层层板。外围主梁采用 2040；
每块净开口层板下方另设四根 2020 承托，用内角码接回主框架。板材尺寸保持 860×240mm。

柱子和底框均落地。底框采用 40mm 竖向截面，接在立柱之间；顶框采用 20mm 竖向截面，放在柱顶，两根长梁覆盖全宽。

### 开放展示架

![开放展示架](display-shelf-open.png)

两面通透，没有背板，三层亚克力层板各有四根 2020 承托。
框架的侧向稳定和承载仍需结合实际连接件、固定方式与载荷判断。

### 工具车

![工具车](rolling-cart.png)

当前 JSON 是工具车的框架与层板示例，含两层四边承托；脚轮、脚轮座和移动时的稳定性未建模。
实际作为移动工具车施工前，需要另选并安装这些部件。

### 工具自检的结果

- **干涉 0**：型材、连接件、板件、构件**四类全部参与**有向包围盒判定
- **装不上的接头 0**：每个接头都有目录里的件能拧上去
- **角码落位错误 0**：856 个内角码的两条臂分别落在实际修剪后的型材槽面上
- 水平层板均有四边承托，独立回归验证每边至少 70% 长度、完整 20mm 承托宽度和真实顶面齐平
- 所有抽屉的两侧都有滑轨安装面；安装面方向、深度与开口位置参与几何校验
- 890 个对接端、856 个内角码；数量是切料与建议依据，不等于每个连接点已经完成结构验算

开门检查覆盖关闭、各构件单独完全打开以及同步完全打开的示例回归；工具的门间运动检查还使用
不超过 1° 的角度采样，包含邻门关闭、半开、全开和同步运动。采样不构成所有独立角度组合的连续碰撞证明。

截图和六份 BOM 可从当前工程重生成：先启动 `npx vite --port 5174 --strictPort`，
再运行 `node scripts/capture-examples.mjs`（需要 Playwright Chromium）。

### 明确没做的

零件目录里还没有：踢脚板、挂墙件/防倾倒件、T 槽封条、端盖堵头、台面及垫板、把手、
滑轨型号、专用层板托、铰链实物件、角码避让缺口。这里的层板承托已用实际型材建模。**调节脚这个件有，但模型里只有 20mm 高**，
不是 100mm 可调脚——所以图上的台面高度是按"不加高脚"算的。这些在
[`docs/ROADMAP.md`](../docs/ROADMAP.md) 的 P3「零件库扩展」里。
