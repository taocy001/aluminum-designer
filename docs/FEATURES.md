# 功能清单

这份文档列出工具**已经做了的每一件事**：它是什么、怎么用、由哪个文件实现。
设计约定与架构见 [`DESIGN.md`](DESIGN.md)，还没做的在 [`ROADMAP.md`](ROADMAP.md)。

---

## 一、画

### 1.1 手持模型，没有"模式"

在左侧点一个型材规格，它就**拿在手里**；点画布落点开画；再点同一个规格、或按 `Esc`，就放下了。
空手时点击即选中。不存在"绘制模式 / 选择模式"这样的开关。
`useToolStore.held` · `DrawingHandler.tsx`

### 1.2 轴向解析绘制

点起点 → 沿某个方向移动 → 点终点。方向不是靠世界坐标猜的，是比较鼠标位移与 X/Y/Z
三轴**在屏幕上的投影方向**，所以和相机角度无关。`X` `Y` `Z` 键可锁定轴向。
`pickUtils.resolveAxisEnd`

### 1.3 画的时候直接敲数字

绘制中键入数字即聚焦长度输入框，回车下单，跳过吸附与取整。拖动中敲数字同理（移动距离、拉伸长度）。
`App.tsx` 的 `precise-input` / `exact-input`

### 1.4 起点拾取的优先级

现有端点（屏幕 24px 内）→ 现有中线上的点（18px 内，沿构件按 5mm 网格）→ 工作面。
选中的端点允许小范围手抖，离开 32px 后释放；被前方构件遮住、或不在指定工作面上的端点不会被保留。
因此可以从立柱顶端、横梁中点等**任意高度**起画。
`pickUtils.pickPoint`

### 1.5 工作面

侧栏「工作面」可把落点平面抬到任意高度（也可「取选中件顶面」）。吊柜就是这么画的。
**抬起工作面是一句声明**：抬起后，不在这个高度上的端点不参与吸附；点在立柱上取它在这个面上的点。
地面（Y=0）不算声明，行为不变。
`pickUtils.pickPoint` 的 `PLANE_TOL`

### 1.6 落地规则

水平构件中心线高度不低于半截面高（2020 → y≥10），从地面起画会自动抬升；立柱从 y=0 起。
拖拽、微调、属性编辑都遵守。
`profileFactory.floorY`

### 1.7 贴面对齐

新画的型材落下去会自动横向平移，让接头的两个面共面，**优先对齐外侧**。
先试**翻转 90°**（2040 转一下就能用 40 面贴 4040），翻转不行才平移。
绘制中的半透明预览包含同样的截面转向、侧移和端部裁切，点击后不会再突然换方向。
起点参考面用黄色显示，当前目标参考面用青色显示；面边框和法向标记指出具体哪一面。
参考面显示已有构件当前可见的面。明确选面时保留旧场景的实体尺寸；未选面及从端盖横向起画时，未固定的型材继续按贯通规则裁切。
选中的侧面实际约束贴合位置：相反两面对应不同落位，沿面法向向外绘制时，实体端面落在参考面上。
向内绘制会显示原因并阻止提交；终点约束冲突时优先保留起点。选面后的精确长度指实际下料长度。
`faceAlign.faceAlignOnCreate` · `tryRoll`

### 1.8 起步模板

工作台、置物架、单门柜、设备机柜、桌腿框架。点一下就有一个可改的东西，长宽高层数在侧栏改。
`templates.ts`

## 二、改

### 2.1 选择

| 方式 | 效果 |
|---|---|
| 单击 | 选中光标下的零件（型材、角码、板件、门、抽屉都可以） |
| `Ctrl/⌘` + 单击 | 加选 / 取消加选 |
| 框选（工具栏的选择开关）| 框内的**所有类型**零件，不只是型材 |
| `Ctrl/⌘ + A` / `+ Shift + A` | 全选 / 取消全选 |
| 双击画布 | 以光标下的位置为中心拉近；空格菜单可选择连通子装配 |
| `Tab` | 光标下重叠时循环切换 |

拾取有两条规则，有先后：**画面上画的是谁，点中的就是谁**（对真实网格做射线检测，命中的直接提到最前）；
都没正对命中时才按屏幕距离和深度决胜负。
悬停和按下使用同一目标；被前方构件遮住的选中端面不会抢走拖动，Tab 可明确切换到后方构件。
`screenPick.ts` · `frontmost.ts` · `PointerRouter.tsx`

### 2.2 移动

拖动零件；或拖 Gizmo 的彩色箭头沿单轴移动；方向键微调 5mm（Shift 为 50）。
拖动中敲数字可精确定距。型材、板件、门、抽屉都能拖，**Gizmo 也都给**——
单选连接件时不直接改变落位。明确与其他零件一起选中的连接件会随整组平移、旋转；
未选中的连接件保持原位，锁定项也保持原位。组编辑只产生一次撤销。
拖动时以黄色标出移动面、青色标出参考面，并显示「端面对齐」「侧面贴合」及对应轴坐标。
相邻平行型材优先齐端面；接近精确中线时仍可居中。已吸附的目标会保持到指针明显移开，完全对齐时提示仍保留。
拖动中按住 Shift 可立即解除吸附，松开后继续移动会重新吸附。斜材只有包围坐标相同时标为「坐标对齐」。
移动、旋转已有型材会保留各件当前的实体端面及下料长度，接头关系变化不会自动拉长或缩短其他型材。
侧栏「重新裁切接头」可明确重算未锁定件；修改贯通规则也会重算。上述操作可撤销，锁定件保持原尺寸。
`DragHandler.tsx` · `editOps.nudgeSelected`

### 2.3 旋转

点 Gizmo 的彩色圆弧，一次 90°，Shift 反向；或侧栏填任意角度绕 X/Y/Z 转。
支点按 `P` 在中心 / 起点 / 终点之间切换。
**旋转中心是选中内容自己的中心**——板件按板心，门与抽屉按它可见的外框中心。
`editOps.rotateSelected` · `selectionPivot`

### 2.4 拉长缩短

空手时拖可见的实体端面；拖动中敲数字指定实体长度，另一端保持不动。
`DragHandler.tsx`

### 2.5 精确定位

属性面板可直接填模型中心线的**起点**和**终点**坐标，或填中心线长度；下料长度另列。
`Sidebar.tsx` 的 `end-position`

### 2.6 截面朝向

2040 这类长方形截面，属性面板可一键转 90°（立着放 / 躺着放是两种构件）。
`faceAlign.rollProfile`

### 2.7 多选批量改

选中多块板可一起改宽高厚和材质；选中多扇门可一起改尺寸、铰链角度、开合程度。
**算一次撤销**，面板上会写明"N 个一起改"。
`panelOps.setPanelsSize` / `setPanelsMaterial` · `fittingOps.updateFittings` / `setFittingsOpen`

### 2.8 镜像与阵列

按整体中心面镜像；沿 X/Y/Z 按间距和份数阵列。都算一条撤销。
`editOps.mirrorSelected` / `arraySelected`

### 2.9 锁定

`L` 锁定/解锁。锁定件仍可见、仍参与吸附与清单，但不会被移动或删除。
`editOps.toggleLockSelected`

### 2.10 复制、撤销、重做、删除

`Ctrl/⌘ + D` / `Z` / `Y` / `Delete`。
复制件保留原件的实体长度；删除邻件不会改变剩余型材的长短。固定端面随文件、分享和本地保存持久化。
`useStore` 的 `past` / `future`

### 2.11 一键修接头

装不上的接头，按"**先转、再挪**"的顺序试着摆正。转一个 2040 不移动不改长，代价为零，所以先试；
不行才挪截面小的那根，±5…±40 逐步试。
**每一步都算过分才保留**：修好一个却弄坏另一个、把两根捅穿、或者把构件挪到够不着邻居，都会被退回。
`repairJoints.ts`

## 三、装

### 3.1 连接件

L 型角码、内角码、加强筋、T 型角码、三维角码、直连板、对接板、端盖、脚轮座、调节脚、
十字连接板、滑块螺母、合页、轴承座。
`connectorCatalog.ts`

### 3.2 角码按槽线落位

一个角码就是两个螺栓，每个螺栓靠一颗 T 型螺母卡进槽里。
**20 面只有一条槽、在正中；40 面是两条槽、在 ±10，正中是实心铝**——角码摆在 40 面正中就拧不上。
所以落位是这样算的：两条腿所在的平面只能是两根方向的叉乘，且必须是两根共有的面；
平面内的两个偏移分别由**对方**型材的槽线决定；哪条腿归谁取决于哪种分法能让角码背面朝外。
`bracketSeat.seatAngle`（内嵌角码）· `seatBracket`（平板）

### 3.3 一键连接所有接头

选一种角码 → 「连接所有接头」。对接端装角码、自由端装端盖或脚。
挤在一起的会沿型材自身滑开（槽是通长的，滑动不会让螺栓离开槽线）。
装不上的接头会被跳过而不是硬塞一个装不上的件。
`autoConnect.ts`

### 3.4 站在地上的件

调节脚、脚轮座装在**端面朝下**的那根构件下面，不是点哪儿装哪儿，也不是最近的那个端点。
`bracketSeat.connectorSeatAt`

### 3.5 板件

选中围住开口的两根构件 → 「生成板件」（**盖在外面**）或「嵌入开口」（**夹在中间**）。
- 贴面板**躺在框上**，不是居中埋在框里；躺哪一面由"背离柜体中心的那一面"决定。
- 嵌入板的尺寸由**整个柜体里横跨这个开口的构件**决定，不是只看你选中的那两根。

材质：密度板、多层板、亚克力、铝板，厚度可填。
`panelOps.ts`

### 3.6 抽屉与柜门是构件，不是散板

选中围住开口的立柱 → 填抽屉高度与个数 → 「加抽屉」；或选铰链边与开启角 → 「加柜门」。

- **柜门朝哪边开**：由柜体自己决定，不是整张图；同一个柜体里已经挂过的门会直接定调，
  免得门朝外、抽屉朝里。
- **柜门只能向外开**：判定后再核对一次它在自己柜体的哪一侧。
- **前平面落在立柱外表面**：门板和抽屉面盖在立柱上，箱体在立柱后面，两者之间隔着一个截面
  ——构件记着这个厚度，否则两者不可能同时对。
- **滑轨间隙**：抽屉箱体每侧让 12.5mm。
- **盖法**：全盖 / 半盖 / 嵌入。共用 20mm 中柱的两扇门做全盖会互压，工具会报干涉。
- **铰链**：35 杯铰（约 110°）、型材合页（可过 180°）、长排合页（180°）；
  数量按铰链安装边长度算（左右开按门高、上下开按门宽；≤900 两个，≤1600 三个，再长四个），都进 BOM。
- **开合模拟与相撞检测**：查看模式下点一下就开，可看抽屉拉出来会不会碰到旁边。

`fittingOps.ts` · `fittingGeometry.ts`

## 四、算

### 4.1 接头修剪

渲染和 BOM 用的是**修剪后的真实几何**，不是中心线长度。
默认「横梁搭在立柱上」时优先级 X > Z > Y，「立柱贯通」时 Y > X > Z；落地立柱下端保持落地。
规则属于工程，可撤销并随保存、导入和分享恢复，会改变图里的接头修剪。中心线长度和**下料长度**是两个数，清单给的是后者。
`jointUtils.computeTrims`

### 4.2 干涉检查

型材、连接件、**板件、门与抽屉**四类一起，用有向包围盒判定。
穿模时标红并指出位置，但**不阻止你继续画**。
板件和构件是靠在金属上的，所以它们的容差是"贴着"和"陷进去"之间的两三毫米。
`analysis.findConflicts`

### 4.3 接头可装配性

端面对接的两根必须**有一条边相等**，且要有一条**两边都是槽**的横向位置，角码才装得上。
2020 顶在 4040 上没有共同边——不报错，但连接件不会装上去，侧栏单列为跨系列采购提示。
一个接头只有一个答案：装不上，是指目录里**没有任何一种件**能拧上去。
`specCompat.ts` · `faceAlign.countUnflush`

### 4.4 角码落位审计

核对每一个已装角码是不是在它能拧上的位置。一个悬空的角码和一个拧好的角码，
渲染出来一模一样，清单里也照样算一个——所以必须单独核对。
`bracketSeat.auditBrackets`

### 4.5 挠度

选中一根横梁，填上载荷重量，按简支跨中或悬挑端集中载荷估算下沉和跨距比例。
- **跨距采用已识别的实际接触支点**，不是构件全长；没有接触的邻近立柱不作为支点。
- 悬挑单独算，并和跨中比"谁沉得多"。
- 型材自重计入。
- 截面属性用查表值，不是从画出来的轮廓算的。
- 下沉/跨距 > 1/200 变琥珀色，并在侧栏汇总。

`deflection.ts`

### 4.6 装配顺序

侧栏「装配顺序」→「分步」，滑块或前后按钮一步步看这套东西是怎么装起来的，
「选中这一步的零件」把该步的件全选出来。

顺序按实际几何接触与高度分批生成，同高同批中立柱优先。连接件随关联型材安排，
板件和门抽屉随后展示；互不相连的组分别安排。
这是拟定装配次序的浏览辅助，不检查螺栓紧固顺序、工具可达性或装配时的临时稳定性，
也不能据此证明实际可装配。

`assembly.ts`

### 4.7 开合相撞

对门的同步开合、单门运动而邻门停在关/半开/全开位置进行离散采样，侧栏列出发现的相撞对。
“采样位置未发现碰撞”不等于证明所有独立角度组合都不相撞。
`fittingGeometry.swingClashes`

### 4.8 下料前检查

汇总干涉、接头、角码落位、运动采样、滑轨安装面、挠度与超长下料件，导出时提示待核对项，但不阻止绘制。
层板显示已识别承托边范围和未识别的边；未识别的边不自动视为结构错误。滑轨检查仅核对已建几何，不能推断未画出的安装板或紧固方式。
挠度采用跨中或悬挑端集中载荷与自重，不计算整柜抗倾覆、接头强度或实际材料公差。这些结果供设计核对，不能替代实物装配和承载验证。

## 五、出

### 5.1 物料清单

按规格和下料长度归并型材，按类型和系列归并角码，紧固件由角码推导，板材按尺寸和材质归并。
表头是固定英文，下游工具不依赖界面语言。
`bom.ts`

### 5.2 原料排料与下料单

按下料长度排 6m / 4m 原料，锯口按每刀 3mm 计，一根上的余料继续切，给出利用率。
下料单 CSV 一根原料一行；超出当前原料长度的件单列 `Unsatisfied`，不计入原料根数与利用率，需换长料或调整设计。
`nesting.ts`

### 5.3 DXF 图纸

正视 / 俯视 / 右视三视图带总尺寸，加全部板件的展开下料图。R12 ASCII，只用 LINE 和 TEXT，分层命名。
`dxf.ts`

### 5.4 STEP 实体

ISO 10303-21（AP214），每个零件按截面和拉伸长度描述。
截面按规格写一次，所有用它的构件共享；长度写的是**下料长度**（已扣接头修剪）。

12 组柜子 470 个实体、1794 个实体条目、91 KB。

**验证范围**：做了结构校验（引用完整、头尾合规、两段 ENDSEC）和**回读比对**
（把文件解析回来，每根构件的下料起点、长度、朝向都要能对上）。
尚未在 FreeCAD 或 Fusion 中验证导入。
`step.ts`

### 5.5 工程文件

JSON，可再导入，版本化（当前 v5，旧文件自动兼容），保存贯通规则和固定端面。载入前统一校验四类零件，失败保留原工程及文件保存目标。
`projectFile.ts`

### 5.6 分享链接

整个工程按列打包 + deflate + base64url 压进 URL 片段，**不经过服务器**，发给别人打开即见。
`shareLink.ts`

## 六、看

### 6.1 视角

左键拖空白转视角、右键拖平移、滚轮或工具栏 −/+ 缩放、`F` 框住选中项（空选时整图）、`F11` 全屏。
双击以光标下的位置为中心拉近。
**转视角的支点**是当前看的那个点——空手在空白处按下会重新取点而不移动画面。

### 6.2 标注

- 总尺寸：整体包围盒三个方向。
- 单件尺寸：板件和构件的 W/H/T **标在它所量的那条边的内侧**，不甩到外面。
- 标注**不画在最上层**：被挡住的零件的标注也被挡住，否则画面全是浮在空中的数字。
- 贴面的标注每帧朝相机倾一点，免得被自己贴的那个面切成两半。

`FrameDimensions.tsx` · `TextSprite.tsx`

### 6.3 查看模式

点一下就开门拉抽屉，用来看会不会撞。开合不算设计改动，不进撤销。
查看模式下不能移动或删除，手柄也收起来。

### 6.4 收起柜门与抽屉

门关上就挡住了框架——这是"画面上画的是谁就点中谁"的直接后果，所以给一个开关把它们收起来。

### 6.5 剖切视图

侧栏「剖切」选 X / Y / Z，滑块决定切在哪里，翻转按钮换成保留另一半。
沿一个平面把一侧整个切掉，不用先决定隐藏哪个零件就能看到内部。

型材、角码、板件和构件均参与剖切，切面不生成实体封口。
被切去的部分不参与拾取。
`Viewport.SectionPlane` · `frontmost.cutAway`

### 6.6 测量

工具栏的尺子：点两点出距离，再点一次收起。
`measure.ts`

### 6.7 操作日志

每次改动按顺序留存，刷新不丢，可一键复制。
`opLog.ts`

## 七、手上的设备

### 7.1 快捷键

| 键 | 作用 |
|---|---|
| `空格` | 光标处弹出快捷盘（选中时是零件动作，空手时是全局动作） |
| `Ctrl/⌘ + A` / `+ Shift + A` | 全选 / 取消 |
| `R` / `Shift + R`，再按 `X` / `Y` / `Z` | 绕指定轴转 ±90° |
| `P` | 切换旋转支点 |
| `L` | 锁定 / 解锁 |
| `F` / `F11` | 框住选中项（空选时整图） / 全屏 |
| `X` `Y` `Z` | 画线时锁定方向 |
| `方向键` / `PgUp` `PgDn` | 微调 5mm（Shift 为 50） |
| `Tab` | 重叠时循环切换 |
| `Ctrl/⌘ + D` / `Z` / `Y` / `Delete` | 复制 / 撤销 / 重做 / 删除 |
| `Shift + 拖动` | 自由摆放，不吸附 |

### 7.2 手势

捏合缩放（触摸板的捏合是带 `ctrlKey` 的 wheel）、双指轻点撤销、长按弹出菜单。
避开了 macOS 占用的三指四指和浏览器的双指横扫。
`Gestures.tsx`

### 7.3 窄屏

侧栏在 768px 以下折叠成底部图标条，可展开。画布常用操作显示文字，其余通过「更多工具」展开，这些画布按钮的触屏命中区至少 44px。

### 7.4 两种语言

中文 / English 一键切换。导出的 CSV 表头固定英文。
`translations.ts`
