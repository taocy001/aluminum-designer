# 交互规则与参考

本页对照当前实现与商业软件、开源项目的公开资料，核对日期为 2026-10-08。对照用于说明操作差异，未进行用户可用性实验。完整快捷键见 [功能与操作](FEATURES.md)。

## 界面与文件

顶栏显示工程名、浏览器备份状态，提供文件、保存、分享及撤销重做。左侧栏分为添加、对象、属性、检查；对象列表支持搜索、类型筛选、隐藏和隔离，制造导出同时可从文件菜单进入；画布空格菜单提供当前位置的操作。

保存窗口显示文件名和保存方式。有原生文件选择 API 时，可写回当前会话中打开的文件，或另存；刷新后需要重新选择写入目标。没有该 API 时下载副本，下载位置由浏览器决定。浏览器备份与本地文件保存分开，备份成功不代表原文件已更新。未保存标记以成功写入的快照为基线。切换工程前提供保存、保留独立草稿或取消；打开工程清空历史，草稿可从文件菜单恢复。

配件选择器使用 24 px 缩略图和 32 px 按钮，收起时显示当前形状，展开后选择型号；悬停或键盘聚焦显示名称及安装说明。选择后或按 Esc 收起。

## 选择与定位

| 情境 | 当前操作 |
| --- | --- |
| 普通选择 | 单击选中一个零件；Shift 单击加选或取消选中。Ctrl/Cmd 单击与普通单击相同 |
| 重叠零件 | Tab / Shift+Tab 轮选；空格菜单的「选择重叠零件」显示光标附近的形状、类型、编号及可识别宿主，可按类型筛选、悬停高亮，用方向键和 Enter 选择。装配步骤隐藏的零件不列入候选 |
| 手持连接件 | 实体跟随鼠标并吸附安装位；Tab / Shift+Tab 切换候选并固定当前节点以便检查；解除固定后继续跟随。不可安装时显示原因 |
| 移动 | 拖动默认吸附，按住 Shift 解除吸附；单个连接件拖动按 0.1 mm 定位，轴向拖动保留其他坐标及朝向。键盘沿世界轴微移 5 mm，按住 Shift 为 50 mm |
| 沿槽细调 | 属性面板输入相对距离，步长为 0.1/1/5 mm，画布显示正负方向及连续支承区间（区间内仍逐位置检查干涉）。面连接件保留安装面、朝向及绑定；越界或干涉时禁止提交，并列出附近有效位置。角接件及端面件通过重新选择安装位定位 |
| 旋转 | 拖动圆弧连续旋转，默认 15° 吸附，Shift 改为 0.1° 精度；点击为 90°、Shift 点击为 −90° |
| 自动连接结果 | 显示新增、已安装、校正和待处理数量。点击失败条目聚焦位置并选择相关宿主及已有连接件；同型号候选显示安装条件，确认时重新校验。按当前工程动态核对，修复后隐藏已解决项，撤销后重新显示；切换工程时清空 |
| 视角 | F 适配所选对象，无选择时适配全图。左键拖空白或中键拖任意位置旋转、右键平移、滚轮缩放；触屏使用手势 |

Shift 单击和拖动按移动距离区分：超过 5 px 后进入拖动。Shift 在选择、拖动和微移中的含义由当前操作决定。

## 键盘作用范围

工程命令使用 Ctrl（Windows/Linux）或 Cmd（macOS）：O 打开，S 保存，Shift+S 另存；C 复制，V 粘贴，D 立即复制；Z 撤销，Shift+Z 或 Y 重做；A 全选，Shift+A 清空选择。Ctrl/Cmd 不参与鼠标多选。

普通编辑快捷键在输入框、下拉框及可编辑文字区域中不执行，按钮保留自己的空格、Enter 和方向键行为。文件快捷键独立处理；模态窗口打开时不再触发。文件菜单与空格菜单支持方向键、Home/End、Esc，关闭后恢复焦点；点击空格菜单外部时先关闭菜单。移动、拉伸和旋转中按 Esc 取消整次手势，保留此前历史；保存和文件切换先取消未完成的手势。

查看模式允许选择、复制、视角操作及开合模拟，禁止设计修改、粘贴和撤销重做。复制内容只保存在当前页面内，打开另一个 JSON 后仍可粘贴；不同标签页或窗口不共享，刷新后清空。连续粘贴相对复制原件按 50、100、150 mm 递增偏移；首根型材沿 X 时沿 Z 偏移，其余情况沿 X。撤销最多保留 50 步，刷新后不保留。

## 与公开实现的对照

| 参考资料 | 参考产品规则 | 本项目对应行为 |
| --- | --- | --- |
| [SketchUp 选择](https://help.sketchup.com/en/sketchup/selecting-geometry) | Shift 切换选中；Windows Ctrl / macOS Option 加选；框选方向区分相交与全包含 | Shift 单击切换选中；Ctrl/Cmd 不加选。多选修饰键并非各产品统一 |
| [SketchUp 移动](https://help.sketchup.com/en/sketchup/moving-entities-around) | 选择移动基点，通过推断参照和轴向约束定位 | 提供吸附、轴向拖动和精确距离输入；连接件另按安装面、槽线及完整孔组定位 |
| [Onshape 选择](https://cad.onshape.com/help/Content/Home/selection.htm) | 画布单击累加或取消，空白或空格清空；列表支持 Shift 连续选择 | 普通单击替换选择，Shift 单击切换，空格打开动作菜单 |
| [Onshape Select Other](https://cad.onshape.com/help/Content/Home/select_other.htm) | 菜单列出重叠对象，用反引号及 Shift+反引号轮选，Enter 确认 | Tab / Shift+Tab 轮选；另提供带筛选和悬停高亮的候选列表 |
| [Blender 默认键位](https://github.com/blender/blender/blob/main/scripts/presets/keyconfig/keymap_data/blender_default.py) | 按编辑器上下文组织键位，F3 搜索命令，空格行为可配置 | 空格菜单按状态提供操作，Ctrl/Cmd+K 搜索命令；键位尚不可配置 |
| [FreeCAD CAD 导航](https://github.com/FreeCAD/FreeCAD/blob/main/src/Gui/Navigation/CADNavigationStyle.cpp) | 区分选择、平移和旋转状态，按鼠标按钮及修饰键切换 | 左键兼作选择、绘制及拖动，空白左拖或任意位置中拖旋转；当前没有导航预设 |

文件、历史、选择和视图命令共用定义表，菜单、命令搜索、帮助与对应快捷键使用同一组名称、执行函数和可用性规则。连续移动、锁轴等操作仍按当前工具状态处理。侧栏不同控件仍有字号与提示样式差异。
