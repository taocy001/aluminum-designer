# 交互评估

对照日期：2026-10-08。依据为产品官方文档、开源项目源码和本仓库实现；以下是功能与操作规则对照，未进行用户可用性实验。

## 参考实现

| 参考 | 可借鉴的做法 | 对本项目的意义 |
| --- | --- | --- |
| [SketchUp 选择](https://help.sketchup.com/en/sketchup/selecting-geometry) | Shift 切换选中状态，Windows Ctrl / macOS Option 加选；左右方向框选分别表示相交与全包含，光标提示增减状态 | 多选没有跨软件统一按键。本项目采用 Shift 切换；应让当前选择规则在光标旁可见 |
| [SketchUp 移动](https://help.sketchup.com/en/sketchup/moving-entities-around) | 选择移动基点、利用推断参照及轴向约束定位 | 安装连接件更适合用孔位、槽线和接触面作为移动参照 |
| [Onshape 选择](https://cad.onshape.com/help/Content/Home/selection.htm) | 画布点选可直接累加，空白或空格清空；列表另有连续选择规则 | 画布、列表和输入框需要各自明确的交互规则，不能混用修饰键习惯 |
| [Onshape Select Other](https://cad.onshape.com/help/Content/Home/select_other.htm) | 重叠对象列成候选菜单，支持键盘选择 | 密集接头应能直接指认要选的零件，减少反复轮选 |
| [Blender 默认键位源码](https://github.com/blender/blender/blob/main/scripts/presets/keyconfig/keymap_data/blender_default.py) | 按编辑器上下文组织键位；F3 命令搜索；空格行为可配置 | 命令应统一声明名称、可用条件和键位，菜单与帮助共用数据；搜索可减少记忆负担 |
| [FreeCAD CAD 导航源码](https://github.com/FreeCAD/FreeCAD/blob/main/src/Gui/Navigation/CADNavigationStyle.cpp) | 导航状态区分选择、平移和旋转；CAD 风格中中键平移、组合按键旋转，并同步修饰键状态 | 鼠标导航与对象拖动需要明确优先级；视角习惯可通过独立预设适配 |

## 当前操作

- Shift 单击加选或取消选中，Ctrl/Cmd 单击与普通单击相同。Shift 拖动用于解除吸附；输入控件保留自己的键盘操作。
- Ctrl/Cmd+C、V、D、Z、Y 分别用于复制、粘贴、立即复制、撤销、重做。复制保存页面内快照，粘贴按 50 mm 偏移；刷新后剪贴板清空。
- Tab / Shift+Tab 可轮选重叠零件；手持连接件时切换安装候选。角接件可在属性面板重新安装。
- 连接件实体跟随鼠标，吸附有效安装位并显示失败原因。单个连接件拖动按 0.1 mm 定位；轴向拖动保持其他坐标及朝向。键盘微移为世界轴 5 mm，Shift 为 50 mm。
- F 适配所选对象，无选择时适配全图；空格打开当前位置的动作菜单。左键拖空白旋转、右键平移、滚轮缩放，触控另有手势。
- 配件选择器使用 24 px 缩略图和 32 px 按钮，默认显示当前形状，展开后可选全部型号；名称及安装说明通过悬停或聚焦显示。

## 待改进项

这些是尚未实现的建议，优先级按影响定位错误和操作成本排序。

| 优先级 | 当前问题 | 建议与验收条件 |
| --- | --- | --- |
| 高 | 已安装连接件虽能吸附，但方向键微移使用世界轴；5 mm 步长不适合槽内细调 | 增加「沿当前槽移动」操作，保留宿主面、朝向与连接关系；可输入距离和选择 0.1/1/5 mm 步长。遇阻时标出冲突零件，并提供有效位置候选 |
| 高 | 重叠件轮选只有先后顺序，密集接头需要多次尝试 | 增加光标处候选列表，显示形状、类型、编号和宿主，高亮预览后确认；保留 Tab 轮选及可选类型筛选 |
| 高 | 自动连接会报告未解决问题，但结果到具体位置的查看仍需手工定位 | 提供结果清单：点击失败条目适配视角、选中宿主并显示原因和候选；明确区分已安装、无适配型号与干涉 |
| 中 | 命令处理、菜单提示和帮助分散维护；部分按钮写死 Ctrl 文案 | 建立统一命令表，按平台显示 Ctrl/⌘，按当前状态禁用命令并解释原因；帮助、菜单和快捷键测试共用此表 |
| 中 | 空格菜单没有命令搜索，功能入口随侧栏区域分散 | 增加可搜索命令入口，支持中文名称、英文别名及键盘上下选择；执行前继续检查锁定、查看模式和输入焦点 |
| 中 | 视角鼠标按键固定，与中键导航习惯不同；左键还负责选中、拖动与绘制 | 增加导航预设并实时显示当前按键说明；鼠标离开画布后释放修饰键、从控件返回画布等情形需覆盖测试 |
| 中 | 侧栏仍混用 9/10/11 px 字号和不同提示方式 | 统一菜单行高、正文与辅助字号、焦点轮廓、浮动说明；保留小图示，触屏增加点击区域。检查窄屏、长型号和键盘操作 |
| 中 | 页面内剪贴板无法跨标签页使用，连续粘贴固定偏移可能产生重叠 | 增加受版本校验的跨页面复制；支持选择基点后粘贴定位，预览冲突并保留一次粘贴一次撤销 |
| 低 | 拖动、绘制和安装对 Shift、Tab 的含义不同，仅靠帮助不易确认 | 在光标或底部状态栏显示当前操作、修饰键效果与 Esc 取消提示；错误信息能指向冲突对象 |

建议先完成沿槽移动、重叠候选与自动连接结果定位，再统一命令和界面样式。已有复制粘贴、轴约束、重叠轮选和安装预览应继续复用。
