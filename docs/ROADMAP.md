# 开发计划 — 对标与缺口

目标：**开源、体验最好、上手无门槛**的铝型材设计工具。

参考对象：MayCAD/Framexpert、Ideabuilder、CraftyAmigo、MISUMI FRAMES（垂直工具），
Fusion 360、SolidWorks Weldments（通用 CAD），FreeCAD + Dodo/Frame/MetalWB（开源）。

---

## 一、我们已经领先的地方

这些不是"也有"，是**对标里基本没有**的：

| 能力 | 说明 |
|---|---|
| **可装配性校验** | 两根型材有没有共同边、有没有一条共同槽线——装不上的接头当场标出来。垂直工具只画形状，不判断能不能装。 |
| **角码按槽线落位** | 螺栓必须落在槽上；40 面正中是实心铝。别家把角码摆在"大概位置"。 |
| **干涉检测** | 型材之间、连接件与型材、连接件之间，全部用有向包围盒判定。 |
| **原料排料** | 按下料长度排 6m/4m 原料，锯口计入，余料续用，出下料单 CSV。 |
| **图纸导出** | DXF：三视图带总尺寸 + 全部板件展开下料图。 |
| **抽屉柜门是构件** | 不是几块散板：滑轨间隙、铰链类型与开启角、开合模拟、相撞检测。 |
| **操作日志** | 每次改动按顺序留存，刷新不丢。 |
| **接头修复** | 装不上的接头一键摆正，每一步都算过分才保留——这是"能判断"之后的下一步："能修"。 |
| **挠度校核** | 选中横梁填载荷，直接报下沉量与 L/n；跨距按支点之间算，不是构件全长。 |

## 二、缺口与计划

### P0 — 上手无门槛（最直接影响"零门槛"） ✅ 全部完成

**1. 起步模板** ✅ `src/utils/templates.ts`
新用户面对空画布不知从哪开始。内置几个常见结构：工作台、置物架、单门柜、机柜、
桌腿框架。点一下就有一个可改的东西，参数（长宽高、层数）在侧栏改。
*理由：对标里只有 CraftyAmigo 提供示例，且不可参数化。*

**2. 分享链接** ✅ `src/utils/shareLink.ts`
把工程压进 URL（或一个短链后端），发给别人打开即见。开源工具的传播主要靠这个。
*已实现：整个工程 deflate + base64url 压进 URL 片段，不经过服务器。*

**3. 测量工具** ✅ `src/utils/measure.ts`
点两点出距离、点一个面出面积。基础到不该缺。

**4. 移动端/平板布局** ✅ 侧栏 720 px 断点 + `src/components/Gestures.tsx`
侧栏在窄屏不可用。手势已经做了（捏合、双指轻点、长按），布局还没跟上。

### P1 — 专业度（把"能画"变成"能交付"）

**5. STEP 导出** ✅ `step.ts` + 侧栏「STEP 实体」
每个对标工具都有（Ideabuilder 除外，那是它被诟病的点）。
没有 STEP 就进不了 FreeCAD/Fusion，也送不进加工厂的 CAM。
*实现路径：型材截面是已知的 2D 轮廓 + 拉伸，写 AP214 的 B-rep 比通用建模简单得多。*

**6. 装配说明书 / 爆炸图** ✅ `assembly.ts` + 侧栏「装配顺序」（分步查看；爆炸图未做）
按装配顺序分步，每步一张图 + 该步用到的零件与螺栓。
**对标里没有一家做**，而这正是个人用户最需要的——图画完了还是不知道先装哪根。

**7. 挠度校核** ✅ `src/utils/deflection.ts`
跨距多长、载荷多重、型材会弯多少。公式是简支梁/悬臂梁，型材惯性矩可查表。
Fusion 要开仿真模块才有，我们可以做成侧栏一行字："这根 1.8m 的 2020 承 20kg 会下沉 6mm，
建议换 2040 或加中撑"。

**8. 剖切视图** ✅ `Viewport.SectionPlane` + 侧栏「剖切」
不靠隐藏零件就能看内部。比"收起柜门"更通用。

### P2 — 规模化（图纸变大之后）

**9. 参数化联动**
改一个总宽，整排柜子跟着走。这是通用 CAD 的核心能力，也是最大的一块。
建议先做**受限版本**：命名尺寸（如"柜宽=600"）被多个构件引用，改它则全改。
不做完整约束求解器。

**10. 分组 / 子装配**
把一组构件命名成"地柜A"，整体移动、复制、隐藏。

**11. 更多型材规格与自定义截面**
V 槽 2020、3060、4080、4545、欧标/国标差异；允许用户按槽宽槽深自定义。

**12. 跨文档复制粘贴**

### P3 — 长期

**13. 零件库扩展**：拉手、气弹簧、滑轨型号、脚杯、线槽、亚克力卡槽件
**14. 渲染出图**：给客户看的效果图（当前是工程视角）
**15. 协作**：多人同时编辑

## 三、明确不做

- **厂商料号与报价**（用户已明确否决）
- **完整约束求解器**：投入产出比不划算，受限参数化已能覆盖大多数场景
- **通用建模**：这是铝型材工具，不是 CAD

---

## 四、建议顺序

```
起步模板 → 测量工具 → 分享链接 → 装配说明书 → STEP 导出
   ↓           ↓          ↓            ↓            ↓
 零门槛      基础缺失    传播        差异化      可交付
```

挠度校核与剖切视图可以插在任何位置，都是独立的小块。
参数化联动放最后，因为它会改动数据模型，越晚做改动面越小。
