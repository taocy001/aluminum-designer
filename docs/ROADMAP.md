# 范围与限制

本文记录当前实现覆盖的范围及使用限制。操作入口见 [功能说明](FEATURES.md)，数据模型和算法见 [架构与实现](DESIGN.md)。

## 型材与连接件

型材库提供 2020、2040、3030、3040、4040 五种矩形截面。截面轮廓、槽线位置、连接件外形和系列缩放遵循本工具的建模约定，没有绑定具体厂商的产品图纸。不能仅凭规格名称判断与实物完全一致。

自动连接根据接头位置、共同截面边、槽线和安装面选择可放置的连接件。不满足条件的位置可能跳过；「连接所有接头」不保证覆盖工程里的所有连接需求。「修复接头」尝试旋转或移动构件，处理后仍需检查剩余提示。

紧固件数量和 M5、M6、M8 等规格由连接件配方推导，不包含螺纹啮合、孔深和工具空间的验证。调节脚与脚轮座也是简化模型；脚轮座不包含完整脚轮，调节脚没有可调行程计算。

## 柜门、抽屉与设备

柜门支持四侧铰链、全盖、半盖和嵌入方式，可将一扇门拆成左右双开门。双开门保留原开口外边，中缝为 3mm；两扇门可独立编辑，不具有联动约束。抽屉按开口生成箱体与抽面，左右分仓的中间型材和安装面需单独设置，没有自动分仓功能。相关板件尺寸、滑轨间隙和运动方式由通用几何规则计算，没有对应特定五金型号。

- 铰链数量由铰链类型及安装边长度估算，未按门重、门宽、材质、重心和具体铰链额定能力选型。拆成双开门后仍需按各扇实际尺寸和载荷选型。
- 抽屉侧面间隙采用每侧 12.5 mm 的模型值；物料清单中的滑轨长度按构件深度记录，未转换为厂商可购买的标准长度。
- 拉手随门、抽屉显示和运动。目前没有独立选型入口，不计入物料清单、DXF 板件图、STEP 实体或碰撞包络。
- 门扇使用固定轴旋转，抽屉沿深度方向平移；未模拟多连杆铰链轨迹、气撑、拉篮、洗碗机下翻门或电器联动机构。开启角是几何参数，限位铰链或限位件没有实体模型，也不会自动加入 BOM。
- 柜体净宽与电器、拉篮的安装尺寸不同。预留空间需扣除连接件、板件、导轨以及水电管线占位，并按设备图纸确认通风和开启空间。

示例工程只包含 JSON 中列出的部件。未建模的台面、背板、侧板、电器或五金不会自动进入清单。逐柜尺寸与注意事项见 [示例说明](../examples/README.md)。

## 检查与承载估算

干涉检查采用包围盒及分部件几何，部分安装在槽内的零件有专门豁免。门、抽屉与其他构件按当前开度检查；门扇之间另外采样多个开度，不能保证任意两个独立开度组合都不碰撞。拉手不参与碰撞检查。

滑轨安装面和层板承托检查只使用已建模型。它们用于发现缺失支承或明显间隙，不验证螺钉拔出力、板材弯曲、连接刚度或整柜抗倾覆性能。

横梁挠度采用预置截面参数、铝材弹性模量和简化梁公式，计算集中载荷及型材自重。程序根据几何推断支点，使用跨中或悬挑端集中载荷计算，并以跨距与挠度之比小于 200 提示关注。这不是整柜有限元分析，也不构成承载能力认证。

没有警告表示当前算法未发现其检查范围内的问题。实际制作还需核对材料数据、固定方式、墙体条件及使用载荷。

## 清单与交换文件

物料清单汇总当前构件及程序推导的五金，不含供应商料号、报价、采购下单或未建模配件。下料排布按长度和锯口进行计算，不处理型材加工工序、孔位排程、板材纹理或封边。

STEP 使用简化实体和装配结构：型材有程序定义的截面轮廓，连接件部分采用占位实体，门抽板件按闭合姿态导出。当前测试包含文件结构校验和几何回读比对；未完成 FreeCAD、Fusion 等外部 CAD 的兼容性验收。

工程文件当前为 v6，兼容导入 v1–v5，导入时校验字段并执行已有迁移。包含双开门会合边的 v6 工程需使用支持该版本的程序打开。迁移不能推断每份工程的使用意图，不会自动把所有历史柜门和抽屉改成同一朝向。使用仓库示例时，以当前 JSON 文件为准。

## 编辑与协作

可以选择连通构件、批量编辑、复制、镜像和阵列。当前没有可命名并持久保存的分组或子装配，也没有跨文档剪贴板、命名尺寸联动或通用约束求解器。

工程通过本地文件及分享链接交换。分享链接内含工程数据，未提供多人同时编辑、服务端项目版本库或权限管理。

项目未提供厂商型材目录导入、自定义截面编辑器、带图装配说明书导出或照片级渲染。现有装配步骤可在界面中查看。
