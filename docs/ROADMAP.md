# 功能范围与计划

| 能力 | 状态 | 范围 |
|---|---|---|
| 起步模板 | 已实现 | 常见框架模板，支持调整尺寸与层数。 |
| 分享链接 | 已实现 | 工程压缩到 URL 片段，在浏览器中加载。 |
| 测量工具 | 已实现 | 两点量距。 |
| 移动端与平板布局 | 已实现 | 窄屏侧栏和触屏手势。 |
| STEP 导出 | 计划中 | 型材与板件的实体交换文件。 |
| 装配说明书与爆炸图 | 计划中 | 装配步骤、零件与紧固件信息及配图。 |
| 挠度估算 | 计划中 | 按跨距、载荷和截面参数估算梁的挠度。 |
| 剖切视图 | 计划中 | 按平面裁去一侧，以查看内部构件。 |
| 参数化联动 | 计划中 | 多个构件引用同一命名尺寸。 |
| 分组与子装配 | 计划中 | 命名构件组，并整体移动、复制和隐藏。 |
| 型材规格与自定义截面 | 计划中 | 扩展规格表，支持自定义槽宽和槽深。 |
| 跨文档复制粘贴 | 计划中 | 在工程之间复制构件。 |
| 零件库扩展 | 计划中 | 拉手、气弹簧、滑轨型号、脚杯、线槽和亚克力卡槽件。 |
| 渲染出图 | 计划中 | 工程视图以外的展示效果图。 |
| 协作 | 计划中 | 多人同时编辑。 |

## 不在计划内

- 厂商料号与报价。
- 完整约束求解器。
- 通用实体建模。
