# 范围与限制

本文记录当前实现覆盖的范围及使用限制。操作入口见 [功能说明](FEATURES.md)，数据模型和算法见 [架构与实现](DESIGN.md)。

## 型材与连接件

型材库提供 2020、2040、3030、3040、4040 I8、4040 B6 六种截面。2020/2040/4040 B6、3030 B8、4040 I8 的轮廓、槽唇、扩腔和芯孔来自 Motedis 厂家 CAD；3040 仍为未核验通用截面，尚无已核验的连接件安装方案，手动安装和自动补齐均不可用。相同外形尺寸可能存在其他厂家的不同槽系，不能仅凭 2020/4040 名称互换。连接件按具体厂家型号建模，来源与简化项见 [连接件说明](../examples/CONNECTORS.md)。

自动连接根据实际型号兼容性、接头位置、完整孔组、槽线和安装面选择可放置的连接件。手动安装与自动补齐共用孔位及干涉检查，自动补齐先修复 20 mm 内同型号同朝向且目标唯一的失位件，保留锁定件、有效件及无法确定目标的已有件。不满足条件的位置列入结果清单，可点击聚焦失败点、检查原因及同型号安装候选；「连接所有接头」不保证覆盖工程里的所有连接需求。「修复接头」尝试旋转或移动构件，处理后仍需检查剩余提示。

紧固件按已核实型号的数量、螺纹、长度及标准列出，部分配件仍缺螺栓长度或转接方案；系统不求解实际螺纹牙型、紧固扭矩、工具空间及完整安装路径。B6 与 I8 混接目前没有已核验内角码；B8/I8 共用槽 8 内角码允许混接。调节脚采用 M8×50 参考件，3030 B8 / 4040 I8 芯孔攻 M8 后直接安装；4040 B6 使用四芯孔攻 M6 的加工转接板，没有可调行程计算。脚轮采用 Motedis 10146 厂家 STEP，用 DIN 7991 M8×25 安装于 3030 B8 / 4040 I8 芯孔。网页与图纸的孔径描述不同，模型采用 STEP 与图纸的 Ø11 版本，采购时须核对版本。4040 B6 端盖是四只 2020 B6 盖组合，保留接缝。具体尺寸及转接板加工图见[配件说明](CONNECTOR-ACCESSORIES.md)。

## 柜门、抽屉与设备

柜门支持四侧铰链、全盖、半盖和嵌入方式，可将一扇门拆成左右双开门。双开门保留原开口外边，中缝为 3 mm；两扇门可独立开合；原门关联洞口时，两扇门按对应宽度区间随框架更新。抽屉按开口生成箱体与抽面，左右分仓的中间型材和安装面需单独设置，没有自动分仓功能。相关板件尺寸、滑轨间隙和运动方式由通用几何规则计算，没有对应特定五金型号。

- 铰链数量由铰链类型及安装边长度估算，未按门重、门宽、材质、重心和具体铰链额定能力选型。拆成双开门后仍需按各扇实际尺寸和载荷选型。
- 抽屉侧间隙、板厚、后部间隙、滑轨长度和行程可编辑，支持底板补强及添加缺少的滑轨支撑。滑轨长度进入清单，但未转换为厂商可购买的标准型号。
- 拉手可按实物填写孔距、突出量、方形截面宽厚、孔径及前板中心偏移；应用后进入物料清单、STEP 和碰撞检查，两个安装孔进入前板显示、孔表、DXF 和 STEP。未配置时仅为示意。当前几何是用户尺寸包络，没有厂家拉手目录或螺纹、安装螺钉自动选型。
- 门扇使用固定轴旋转，抽屉沿深度方向平移；未模拟多连杆铰链轨迹、气撑、拉篮、洗碗机下翻门或电器联动机构。开启角是几何参数，限位铰链或限位件没有实体模型，也不会自动加入 BOM。
- 设备占位以用户填写的盒体尺寸和六面预留检查已建模几何；不提供设备目录、连续开门轨迹或进场路径验证。未建模的水电管线不参与检查，通风和安装间隙应按设备图纸填写。

示例工程只包含 JSON 中列出的部件。未建模的台面、背板、侧板、电器或五金不会自动进入清单。逐柜尺寸与注意事项见 [示例说明](../examples/README.md)。

## 检查与承载估算

型材、板件和门抽板件之间的干涉使用包围盒检查。连接件采用分块凸体；与型材检查时，使用保留槽唇、扩腔、槽底和芯孔的厂家截面挤出实体。内角码及槽螺母的宿主须匹配槽线、朝向和安装面；端盖压入配合和攻牙连接仅在已核验宿主上应用局部装配规则。连接件开口保留，孔洞或圆弧的碰撞包络可能偏保守。与其他连接件、板件和设备检查完整分部件。门、抽屉与其他构件按当前开度检查；门扇之间另外采样多个开度，不能保证任意两个独立开度组合都不碰撞。已配置尺寸的拉手包络参与上述检查，示意拉手不参与。

滑轨安装面和层板承托检查只使用已建模型。板材固定支持胶合板/MDF（厚 6–40 mm）与 2020/2040/4040 B6、3030 B8 和 4040 I8 型材。内嵌水平板用连接片跨接横梁，0–20 mm 间距以垫套填实；贴合型材外表面的顶板、背板及侧板用穿板螺栓直接连接槽螺母。B6 / B8 / I8 分别配 M5 / M6 / M8 五金。跨接方案限水平板，直装方案要求板面平行且贴合宿主安装面；不覆盖 3040、其他材料或未建模托件，也不验证承载能力。滑轨检查接受覆盖至少半段轨长的侧向安装面，或前后立柱组合；「补齐滑轨支撑」仅把侧向安装面视为已具备支撑。该检查不验证具体滑轨孔位、螺钉拔出力、板材弯曲、连接刚度或整柜抗倾覆性能。

横梁挠度采用预置截面参数、铝材弹性模量和简化梁公式，计算集中载荷及型材自重。程序根据几何推断支点，使用跨中或悬挑端集中载荷计算，并以跨距与挠度之比小于 200 提示关注。这不是整柜有限元分析，也不构成承载能力认证。

没有警告表示当前算法未发现其检查范围内的问题。实际制作还需核对材料数据、固定方式、墙体条件及使用载荷。

## 清单与交换文件

物料清单汇总当前构件及型号配方中的五金，连接件提供已核实参考料号；不提供报价、采购下单或未建模配件。零件编号用于工程内追溯，不能替代供应商料号。型材排料按长度和锯口计算；板材排版按材质、厚度分组，计入边距与锯缝，可选择旋转 90°。板孔表输出已安装板材固定件的通孔及已配置拉手的前板通孔。板件可设置纹理和四边封边厚度，排版按扣尺后的毛坯与纹理约束计算；图纸保留成品尺寸、毛坯尺寸和封边标注。不处理型材加工工序和孔位排程。

STEP 使用简化实体和装配结构：已核验型材采用厂家截面轮廓及芯孔，连接件采用显示模型的实体，门抽板件和已配置拉手按闭合姿态导出。相邻共面三角面合并为带孔环的平面；相同连接件共享局部闭壳、面和顶点，每件保留独立实体记录、名称及世界位置、朝向。曲面仍为分面，纯视觉标记不导出，多个实体不做布尔合并。单元测试检查引用、型材几何及连接件闭壳；Open CASCADE 8.0.1 回读已覆盖重复直连板、三个槽 8 内角码的九个实体，含实测拉手的两个装配零件、四个实体，以及各三件的 I8 直装和跨接板材固定件，并核对逐件名称、世界包围盒、体积及再次导出后的回读。FreeCAD 1.1.4 界面验收覆盖板材、内角码、加强角码、三维角块、上述重复件、实测拉手和 I8 板材固定件。仓库宏支持传统 App::Part 导入结构，核对逐件名称、位置、体积、实体数和有效性；其余型号、App::Link 导入模式及 Fusion 界面兼容性尚未验收。

带图装配说明可导出为独立 HTML 并打印。图示采用零件实体盒轮廓，步骤按几何接触和高度安排，不验证工具空间、紧固顺序或临时稳定性，也不包含加工工艺。

工程文件当前为 v12，兼容导入 v1–v11。无版本及 v1–v5 数据导入时执行旧格式迁移；v6 及后续版本只做字段校验，保留已有抽面尺寸与叠抽标记。当前格式保存设备本体及预留、抽屉结构参数、洞口/支撑/板材固定关联、模板实例、分组、板件加工参数及拉手尺寸。使用仓库示例时，以当前 JSON 文件为准。

## 文件、编辑与协作

可以选择连通构件、批量编辑、复制、镜像和阵列，并显式关联洞口与派生部件。关联只支持既定依赖方向，不求解循环约束。支持命名分组、选择及保存成员关系；分组没有独立局部坐标或装配约束。新建模板整组平移或旋转后，保存重开仍可再次编辑尺寸，保留整组姿态；成员数量变化、单根成员改动、删除或锁定会阻止修改。参数更新保持成员编号，并更新既有洞口、滑轨和支承关联。板材固定件保留宿主、槽位、安装面和沿板位置比例，随尺寸更新；未关联零件、无效安装位、更新后干涉或锁定件需要移动时阻止整次修改。旧工程不推断模板来源。尚无跨标签页共享的零件剪贴板、命名尺寸联动或通用约束求解器。同一页面内打开另一个 JSON 后可粘贴已复制的零件，刷新后剪贴板清空。

顶栏显示工程名，文件菜单与保存窗口提供打开、保存和另存。浏览器支持原生文件选择 API 且使用可信 HTTPS 或 localhost 时，可写回当前会话中选定的文件；刷新后文件名保留，写入句柄不保留，需要重新选择目标。普通局域网 HTTP 或没有该 API 时下载副本，下载位置由浏览器控制。浏览器自动备份用于刷新恢复，不会自动写回本地原文件。工程草稿独立保存，可在文件菜单恢复。切换有未保存修改的工程时提供保存、保留草稿或取消；草稿写入失败时不替换工程。打开新工程清空撤销历史，成功写入磁盘后按实际保存快照更新未保存标记。

工程通过本地文件及分享链接交换。分享链接内含工程数据，未提供多人同时编辑、服务端项目版本库或权限管理。

项目未提供厂商型材目录导入、自定义截面编辑器或照片级渲染。
