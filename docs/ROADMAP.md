# 开发计划

目标：**开源、体验最好、上手无门槛**的铝型材设计工具。
已做的功能见 [`FEATURES.md`](FEATURES.md)，这里只列没做的。

---

## 对标（2026-09 调研）

| 工具 | 形态 | 关键短板 |
|---|---|---|
| MayCad | Windows 桌面，注册审批 | 卡顿；连接件自动但不可控、方向常错；无中文 |
| item Engineeringtool | 浏览器，注册墙 | 厂商锁定；云端主数据可能改历史项目 |
| MISUMI FRAMES | Windows 5GB | 厂商锁定；BOM 只加不减；无镜像/阵列 |
| 80/20 IdeaBuilder | 浏览器 | 没有测量工具；知识产权条款引发用户担忧 |
| 嘉立创FA | 浏览器 | 画错只能删了重画；闭环料价高 |

三条结论：

1. **"画线 + 接头自动修剪 + 连接件自动推导"是行业收敛出的范式**——我们已做到，
   且修剪语义有测试背书。
2. **精确输入与自由编辑是行业普遍短板，我们已领先**：精确长度键入、撤销重做、
   拖拽、多选、镜像/阵列，对手或缺或弱。
3. **商业软件全部是静态死模型 + 厂商锁定**。可动装配（门能开、抽屉能拉、
   运动干涉检查）加供应商中立 BOM 的组合市场上不存在——这是差异窗口。

## 缺口与计划

### P1 收尾

**装配说明书的出图/导出**：装配顺序已能分步查看（`assembly.ts`），
还不能导出成一份带图的说明书。

### P2 — 规模化

1. **参数化联动**：命名尺寸（如"柜宽=600"）被多个构件引用，改它则全改。
   不做完整约束求解器。会动数据模型，越晚做改动面越小。
2. **分组 / 子装配**：一组构件命名成"地柜A"，整体移动、复制、隐藏。
3. **更多型材规格与自定义截面**：V 槽 2020、3060、4080、4545、欧标/国标差异；
   规格表数据驱动，允许用户按槽宽槽深自定义。
4. **跨文档复制粘贴**。

### P3 — 长期

1. **零件库扩展**：拉手、气弹簧、滑轨型号、脚杯、线槽、踢脚板、挂墙/防倾倒件、
   T 槽封条、层板托、台面及垫板、100mm 可调脚（当前调节脚模型只有 20mm 高）。
2. **渲染出图**：给客户看的效果图（当前是工程视角）。
3. **协作**：多人同时编辑。

---

## 明确不做

- **厂商料号与报价**（用户已明确否决）
- **完整约束求解器**：投入产出比不划算，受限参数化已能覆盖大多数场景
- **通用建模**：这是铝型材工具，不是 CAD

---

## 已知未验证项

STEP 导出（`step.ts`）做了结构校验和回读比对（引用完整、每个构件的下料
起点/长度/朝向都能从文件里读回来），但**没有在 FreeCAD 或 Fusion 里实际打开
验证过**——开发机上没装。
