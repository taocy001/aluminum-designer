# 铝型材框架设计器

在浏览器中绘制铝型材框架、添加板件和柜门抽屉，并导出物料与下料清单。

![绘制单门柜、添加连接件和柜门、查看清单](docs/demo.gif)

![12 组柜体示例](examples/apartment-12-units-overview.png)

[`examples/flat/`](examples/flat/) 包含 12 份独立工程 JSON，涵盖厨房柜、鞋柜、电视柜、衣柜、书桌、书架、洗衣柜、餐边柜和浴室柜。合计 570 根型材、1576 个连接件、38 块独立板件和 39 个门或抽屉（27 扇门、12 只抽屉），型材下料总长 370.844 m。框架接头的安装范围见[示例说明](examples/README.md#连接件安装范围)。门与抽屉内部生成的板件另外计入物料清单。

[`examples/`](examples/) 还提供 L 形橱柜、四门衣柜、书桌、高书架、开放展示架和工具车六个示例，以及对应截图和 CSV。示例说明列出了柜体净宽、设备预留和未建模的部件；它们是可编辑的设计样例，不能直接作为完整施工图。

## 功能

- **绘制与编辑**：六种型材规格，轴向绘制、精确长度输入、端面拉伸、移动、旋转、多选、镜像和阵列。
- **接头处理**：按横梁或立柱贯通计算端部修剪，分别保留中心线长度和下料长度；提供贴面对齐、接头检查及修复操作。
- **柜体构件**：独立板件、柜门、抽屉及随面板运动的拉手；支持开合预览、抽屉结构参数、底板补强、补齐滑轨支撑和水平木板固定。
- **设备占位**：输入设备本体尺寸及六面安装预留，随位置和朝向检查实体干涉与预留不足；不计入材料清单。
- **检查**：当前开度下的几何干涉、接头落位、门扇之间的采样运动碰撞、滑轨安装面、层板支承，以及横梁挠度估算。
- **清单与排料**：型材按规格和下料长度汇总，连接件按类型和系列汇总，端盖按完整截面区分，4040 B6 调节脚及转接件单独列出；生成板材尺寸、紧固件建议及原料切割方案；零件编号与模型和导出文件对应。
- **文件**：本地工程保存、导入、分享链接、CSV、DXF、STEP 和带图装配说明 HTML 导出。

功能入口和操作细节见 [功能说明](docs/FEATURES.md)。检查采用简化几何和计算参数，适用范围见 [范围与限制](docs/ROADMAP.md)。

## 启动

```bash
npm ci
npm run dev
```

开发服务默认地址为 `http://localhost:5173`；端口占用时以终端输出为准。

使用 Docker 启动生产版本：

```bash
docker compose up -d --build
```

访问 `http://localhost:4174`。

## 基本操作

在侧栏选择型材规格后，点击画布确定起点，沿目标方向移动，再点击确定终点；也可以直接输入长度并回车。再次点击已选规格或按 `Esc` 放下构件，进入选择操作。

| 操作 | 方法 |
|---|---|
| 在目标高度起画 | 吸附到已有型材，或设置工作面高度；可取选中立柱的顶面 |
| 锁定绘制方向 | 按 `X`、`Y` 或 `Z` |
| 移动 | 拖动型材，或拖动操作器的彩色箭头；拖动时可输入距离 |
| 拉长、缩短 | 拖动已选中型材的端面；可输入长度 |
| 修改坐标 | 在属性面板填写起点、终点 |
| 旋转 | 点击操作器圆弧，或按 `R` 后指定轴；`Shift` 反向，`P` 切换支点 |
| 调整矩形截面朝向 | 在属性面板旋转截面 90° |
| 修改贯通规则 | 侧栏选择横梁贯通或立柱贯通 |
| 添加连接件 | 展开侧栏形状选择器，选后自动收起；鼠标移动时显示实体预览，靠近可安装位置自动吸附，可筛选构件组合、点击位置编号或用 `Tab` 轮选；「连接所有接头」添加可安装位置 |
| 添加板件 | 选择围成开口的型材，再选择外盖或嵌入板件 |
| 添加柜门 | 选择前开口两侧立柱，设置铰链和盖合方式后添加；选中门后可在属性中「拆为双开门」 |
| 添加抽屉 | 选择能围出宽度和深度的四根立柱，设置抽面高度和叠放数量后添加 |
| 检查开合 | 使用构件属性中的开度，或在查看模式点击门、抽屉 |
| 检查接头 | 查看侧栏提示；执行「修复接头」后核对剩余问题 |
| 量距 | 使用工具栏尺子，依次指定两个点 |
| 使用示例 | 导入示例 JSON；也可从侧栏模板创建框架 |

绘制时，黄色标出新构件的面，青色标出参考面。有接触面积的对应面显示「贴合」，远处共面显示虚线「对齐」，未满足的目标显示红色。移动时，紫色虚线表示参考面或中心对齐；按住 `Shift` 可自由放置并隐藏这些参考线。

连接件选择器显示实际模型缩略图，悬停或键盘聚焦查看名称和安装说明；型号与厂家来源见所选件的属性面板。画布中连接件实体跟随鼠标，吸附到通过安装校验的位置。角接件预览高亮当前关联型材，点击安装到预览位置；无有效孔位或存在干涉时显示原因。固定节点后可切换槽位、朝向及构件组合，已放角接件可重新安装。连接件也可独立移动、旋转。「连接所有接头」先修复距有效安装位不超过 20 mm、同型号同朝向且目标唯一的失位件，再补齐缺件；锁定件和其他已有件保留，未解决的安装问题会提示。单个连接件拖动以 0.1 mm 定位并吸附有效安装位，轴向拖动保持其他坐标和朝向；按 `Shift` 解除吸附。2040 的 40mm 面垂直对接且槽线对齐时，两槽均可手动安装或自动补齐；三方向接头检查全部两两配对，第三根型材挡住连接件时拒绝落位。连接件各块实体的投影轮廓外有 20px 拾取容差，真实遮挡优先，重叠件仍可轮选。

双开门的铰链位于两侧外边，中间留 3mm 缝。抽屉左右分仓需要对应的框架和两侧滑轨安装面；界面中的抽屉数量设置用于上下叠放，不会自动增加分仓型材。

从沿世界 X/Z 轴的横梁上向上画立柱时，可在上表面端边选择「端面齐边」起点；T 形交汇处可选择「接口齐平」。预览显示采用哪根横梁的表面作为参考，确认后按 `Y` 沿竖向绘制。

## 常用快捷键

输入框、下拉框和开度滑块获得焦点时，按键由控件处理。使用画布快捷键前，先结束控件输入并移开焦点；查看模式仅开放选择、视角等操作。

| 快捷键 | 作用 |
|---|---|
| `空格` | 在光标处打开动作菜单 |
| `Ctrl/⌘ + A`、`Ctrl/⌘ + Shift + A` | 全选、取消选择 |
| `Shift/Ctrl/⌘ + 单击` | 加选或取消选中；`Shift + 拖动` 仍为自由移动 |
| `Ctrl/⌘ + C`、`Ctrl/⌘ + V` | 复制选中构件、粘贴副本，每次粘贴可一次撤销 |
| `Ctrl/⌘ + D` | 立即复制并偏移 |
| `Ctrl/⌘ + Z`、`Ctrl/⌘ + Y` | 撤销、重做 |
| `Delete` | 删除未锁定的选中件 |
| `L` | 锁定、解锁 |
| `F` | 适配选中项；未选择时适配整图 |
| `F11` | 切换全屏 |
| `Tab` / `Shift + Tab` | 向前 / 向后轮选重叠件；手持连接件时轮选安装位置 |
| `方向键`、`PgUp`、`PgDn` | 沿轴微调 5 mm；按住 `Shift` 为 50 mm |
| 左键拖空白、右键拖、滚轮 | 旋转视角、平移、缩放 |
| 双击画布 | 向光标下的位置拉近 |
| `Esc` | 取消当前操作或放弃未提交的输入 |

宽度小于 768px 的界面使用底部侧栏；「更多工具」展开其余画布操作。

## 导出与保存

| 格式 | 内容 |
|---|---|
| 物料清单 CSV | 型材下料尺寸、连接件、推导的紧固件、板件及门抽五金，实体零件附编号；表头为固定英文 |
| 下料单 CSV | 原料切割分配、逐段编号、锯口和余料；超长件单独列出 |
| DXF | 型材、连接件、独立板件及关闭门抽板件的三视图、总尺寸和板件展开图，附零件编号 |
| STEP | 型材、板件、闭合状态的柜门与抽屉板件，以及简化连接件实体 |
| 装配说明 HTML | 可离线查看、打印的概览图、分步图、材料清单和下料表 |
| 工程 JSON | 当前文件格式 v10；包含设备占位、构件、洞口与支撑关联、抽屉结构参数、板材固定关联、姿态和贯通规则，兼容导入 v1–v9 |
| 分享链接 | 工程数据压缩到 URL 中；打包格式 v9 保存设备占位、零件 ID、关联、连接件槽系、板材固定关联及构件参数，兼容旧链接 |

工具栏「零件编号」显示模型编号；属性面板可复制完整编号，展开清单行可查看对应零件。移动、旋转、改尺寸、保存重开和分享保留编号，复制的新件使用新编号。

导出前应查看「下料前检查」。有待核对项时，文件仍会导出，并显示核对提示。门宽、板厚、滑轨规格、铰链承重、设备安装间隙和实际型材截面仍需按选用的产品核对；显示拉手目前不计入清单和几何碰撞检查。

## 开发与验证

```bash
npm test
npx playwright install chromium
npm run build
npm run test:prod
npm run test:e2e
```

浏览器测试使用 Playwright。`test:prod` 在 4175 端口测试已构建的 `dist/`，通过真实 UI 检查创建、编辑、导入、自动保存、恢复和清单下载；`test:e2e` 在 5174 端口运行开发服务的完整 E2E。`npm run test:all` 按上述顺序执行全部检查。Linux 可用 `npx playwright install --with-deps chromium` 安装浏览器和系统依赖。

[CI](.github/workflows/ci.yml) 在推送和 PR 时执行依赖安装、单元测试、生产构建及两类浏览器测试；失败时保留截图和 trace 7 天。测试配置、代码结构和部署说明见 [架构与实现](docs/DESIGN.md)。
